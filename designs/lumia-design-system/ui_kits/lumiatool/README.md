# LumiaTool Tool Page Kit

Starting points represent layout contracts, not product mock data. Choose the template matching the tool task, then replace content while keeping panel hierarchy, control placement, state behavior and responsive rules.

- Transformer: source → result.
- Inspector: raw input → structured output.
- Generator: options → preview/result.
- Tester: configuration/action → workspace/log.
- Editor: command bar → editor/diff.
- Diff is an Editor specialization.
- Utility uses compact forms and nearby results; do not stretch it into a two-pane canvas.
